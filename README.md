# Bet Tournament

Сервис «Турнир на ставках»: NestJS + PostgreSQL + RabbitMQ.

Очки начисляются по событиям `bet.settled` (1 очко за 1 USD выигрыша, валюты
конвертируются по курсам из конфига), отменяются по `bet.rollback`.
Лидерборд: топ-100 + позиция игрока из заголовка `X-Player-Id`.

Статус: план реализации — [PLAN.md](PLAN.md). Код появится после его аппрува.
